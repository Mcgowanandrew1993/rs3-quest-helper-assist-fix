# Local reward-screen text recognition

Tesseract.js 6.0.1: https://github.com/naptha/tesseract.js

Tesseract.js-core 6.1.2: https://github.com/naptha/tesseract.js-core

English fast model: https://github.com/tesseract-ocr/tessdata_fast

These projects use the Apache License 2.0. License texts and bundled third-party
notices are included in this directory. The model was downloaded from the
tessdata_fast main branch on 2026-10-28.

The worker, WebAssembly core and English model are served from the local addon
server. No screenshot or recognised text is sent to an external OCR service.
